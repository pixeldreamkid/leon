# Orgo

Connects Leon to [Orgo](https://www.orgo.ai) cloud computers (Linux, Windows and macOS) through Orgo's hosted MCP server at `https://www.orgo.ai/mcp`.

## Setup

Sign in with Orgo's OAuth flow when Leon first connects, or put your Orgo API key in Leon's local config. Never commit the key to the repository.

## Abilities

- Run shell commands (Bash on Linux, PowerShell on Windows) and Python
- Take screenshots of a computer's screen
- Click, drag, scroll, type text and press keys
- Create, start, stop and restart computers
